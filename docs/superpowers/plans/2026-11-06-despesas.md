# Página Despesas "para onde foi o dinheiro" — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Trocar o miolo de `#viewDespesas` pelas 6 faixas da spec (Topo, Categorias que abrem, Gastos mês a mês, O que mudou, Maiores gastos, Resumo), também comparando.

**Architecture:** Contas puras num módulo novo `frontend/js/despesas.js` (`window.Despesas`, testado em node). `painel.js` ganha `renderDespesas()` (normal) e `renderDespesasComparacao()` reescrita; o par de meses de "O que mudou" sai de `renderDashboard` para uma função compartilhada. HTML novo em faixas (`card faixa`), CSS reaproveitando `.faixa`, `.cmp-*`, `.tag-per`.

**Tech Stack:** ES5, `node --test frontend/tests`, `pytest`, puppeteer no scratchpad (`pup/`, banco temporário, porta 5055).

**Spec:** `docs/superpowers/specs/2026-11-06-despesas-design.md`

## Global Constraints
- Saída = `saiDaConta` (sem movimentos internos; estornos descontam). Categorias com valor ≤ 0 não aparecem na lista nem no "O que mudou".
- "por mês" = divisor do Dashboard (`Periodo.fatorMes`/`dadosPeriodo`); divisor 1 → "em <nome curto>".
- Fixas = categorias em `FIXED`; Dia a dia = saídas − fixas; as duas porcentagens somam 100.
- Cores: fixas/mês mais caro = `--accent`; dia a dia/barras neutras = `--s2`; P1 = `--accent`, P2 = `--s2`.
- Reduzir movimento → nada anima. Animar só ao abrir a página ou trocar de período/categoria aberta.
- Textos em português simples; números em `brl`/`brl0`/`pct` já existentes.

## Review Focus
1. Período de uma semana → sem gráfico da categoria, sem "O que mudou", Gastos por dia (Task 3/4).
2. Extrato que termina no meio do mês → barras "(parcial)" mais claras e fora da média (Task 1 `serie`, Task 3).
3. Categoria com estorno maior que o gasto (valor negativo) → fora da lista e das mudanças, fixas + dia a dia ainda somam o total (Task 1, Task 2).
4. Categoria aberta que some ao trocar de período → fecha sem erro (Task 2).
5. Comparar ligado e depois "Sair" → faixas normais voltam, sem restos das barras duplas (Task 4).

### Task 1: módulo puro `despesas.js`
**Files:** Create `frontend/js/despesas.js`, `frontend/tests/despesas.test.js`; Modify `frontend/index.html` (script antes de `painel.js`).
**Produces:**
- `divisao(byCat, fixas:string[], outs) → {fixas, dia, pFixas, pDia}` (pFixas+pDia = 100, inteiros por maior resto; outs 0 → tudo 0; categorias negativas não somam nas fixas).
- `origens(lista:[{chave,rotulo,valor}], n) → {top:[{rotulo,valor,pct}], resto:{n,valor}|null, total}` (agrupa por chave, rótulo = o primeiro visto, ordem por valor).
- `serie(unid:[{chave,rotulo,valor,parcial}]) → {barras:[…+{maior:bool}], media}` (maior = maior valor entre todas; média só das não parciais, ou de todas se todas parciais; vazia → media 0).
- `mudancas(A:{cat:v}, B:{cat:v}, n) → {subiram:[{nome,a,b,d,txt}], cairam:[…]}` (B = mais recente; ignora a<0 ou b<0 e |d|<0.01; txt `'nova'` se a≤0, senão `'+27%'`/`'−100%'` arredondado; n de cada lado).
- `frases(ctx) → [{w:bool,t:string}]` com ctx `{semCat:{n,v}, taxas:{nome,v,ins}, cats:[{nome,v}], outs, diasRenda:int|null}`; ordem e textos da spec §6 (taxas: aviso se v/ins > 0.05; "3 maiores" só com 4+ categorias; diasRenda null → sem frase).
- [ ] Testes (valores exatos): `divisao({Moradia:300,Mercado:200,Lazer:-50},['Moradia'],450)` → fixas 300, dia 150, pFixas 67, pDia 33; `origens` com 5 chaves e n=3 → resto `{n:2,valor:…}`; `serie` com a última parcial e maior → `maior` nela, média só das outras; `mudancas({A:100,B:50,C:-5},{A:150,B:0,D:30},2)` → subiram `[A +50 '+50%', D 'nova']`, cairam `[B −50 '−100%']`, C ausente; `frases` sem nada → `[]`; com 17 sem categoria → 1ª frase `w:true` contendo "17 despesas ficaram sem categoria".
- [ ] RED → implementar → GREEN (`node --test frontend/tests`) → commit "Despesas: contas puras da página".
